## 📌 Sobre o Projeto
Este repositório contém os códigos e rotinas desenvolvidos como parte do projeto de Iniciação Científica (PIBIC/CNPq - Edital PRPPG/UFBA 005/2026) intitulado **Extração e Processamento Automatizado de Dados Geométricos de Modelos BIM no Formato IFC para Verificação de Conformidade de Armaduras**.

O objetivo principal é desenvolver um módulo funcional em Python para a leitura e estruturação de dados geométricos de armaduras (como `IfcReinforcingBar` e `IfcReinforcingMesh`) a partir de modelos BIM no padrão aberto IFC (ISO 16739). Os dados extraídos são estruturados para servir como base de referência e comparação em um algoritmo de verificação de conformidade utilizando Inteligência Artificial (IA)[cite: 2].

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python
* **Manipulação IFC:** IfcOpenShell[cite: 2]
* **Análise e Estruturação de Dados:** Pandas
* **Ambiente de Desenvolvimento:** Visual Studio Code (VS Code)
